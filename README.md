# Bible AI

Bible AI is a Scripture-centered knowledge base and conversational system designed to help people understand the Bible through clear, concise, traceable answers.

## Foundation

The project begins with three governing documents:

- [Mission Statement](foundation/mission.md)
- [Strategy](foundation/strategy.md)
- [Statement of Faith](foundation/statement-of-faith.md)

These documents define why the project exists, how the chatbot should operate, and the theological boundaries that govern its content.

## Status

Early requirements and design stage.
